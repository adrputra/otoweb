# Routes

## Public

- `/` — public showroom home.
- `/cars` — published vehicle listing.
- `/cars/[slug]` — vehicle detail page.

## Admin

- `/admin` — dashboard with inventory and lead summaries.
- `/admin/vehicles` — responsive inventory table/cards with filters and actions.
- `/admin/vehicles/new` — create vehicle form.
- `/admin/vehicles/[id]/edit` — edit vehicle form.
- `/admin/leads` — lead list and status controls.
- `/admin/staff` — staff list and invite dialog.
- `/admin/settings` — showroom, domain placeholder, and account tabs.
- `/admin/settings/showroom` — showroom profile and live preview form.
