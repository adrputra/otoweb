# Responsive behavior

The admin UI is mobile-first and tested at 375px, 768px, and 1440px widths.

- Desktop uses a persistent sidebar, compact content panels, and sticky section navigation where forms are long.
- Mobile uses a bottom navigation/drawer pattern, stacked cards, horizontally scrollable controls, and sticky form actions.
- Vehicle inventory renders as a dense table on desktop and action-friendly cards on mobile.
- Vehicle creation/editing uses a mobile stepper and a single desktop page with sticky section navigation.
- Showroom settings stack the form and preview on narrow screens and use a two-column layout on desktop.
- Controls retain visible focus states, semantic labels, and accessible alternatives for drag-and-drop actions.
